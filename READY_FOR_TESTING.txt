🚀 QUICK START (After getting image)

1. Write to USB:
   sudo dd if=loki-streamos-YYYYMMDD.img of=/dev/sdX bs=4M status=progress

2. Boot Loki Zero:
   - Insert USB
   - Power on + hold Volume Down (boot menu)
   - Select USB device

3. Test Hardware:
   - Run: sudo ./scripts/diagnostics.sh
   - Send results back for iteration
